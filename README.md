# YOU-N-I-VERSE · Worlds library

This is the index of the world runtimes, agent spaces, self-discovery games, personal-world experiments and world-builder donor projects found across the user's GitHub and Drive. **They remain separate projects.**

## Worlds category

- **[Worlds & games — source catalog](worlds/CATALOG.md)**: what each of the 21 inspected or located projects contains, its current limitations, and its original GitHub/Drive source.
- **[Worlds model](worlds/WORLD_MODEL.md)**: intended Worlds page, agent-only worlds, human/agent spaces, the personal Indieverse, activities, persistent identities and Morph boundaries.
- **[Machine-readable registry](worlds/REGISTRY.json)**: a searchable JSON manifest for a later Worlds page.

**Status:** catalog and source pointers only. This is not a deployed game lobby, not a new APK, and not a claim that the worlds have been merged or are playable. Some records represent builders, early prototypes or bootloaders, and are labeled as such. Catalog inspected 2026-10-29.

## Preservation

The originals remain on Google Drive or their existing GitHub branches. Do not throw away the richer original project or replace a world with a minimal demo. Source archives, dependency folders, binaries and embedded git histories are **not imported** into this public repository; this is a clean source map rather than another 800-MB archive dump.

Related active project: [SynthWorld Godot](https://github.com/justappgrabbin/SYNTHWORLD-). Its playable scene and missing Morph assets are distinct from this catalog.
